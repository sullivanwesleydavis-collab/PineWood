# PineWood
A simple 3D forest exploration game with pine trees, muntjacs, and a visible player hand.

## Play locally
Open `docs/index.html` in your browser, then click to lock the pointer and use `WASD` to move.

## GitHub Pages
If GitHub Pages is enabled for this repository, the game will be available at:

`https://sullivanwesleydavis-collab.github.io/PineWood/`

The site uses the `docs/` folder as the published site root.
